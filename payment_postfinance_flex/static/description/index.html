PostFinance Checkout Flex Payment Integration for Online Store

Payment Page. Mobile friendly.

PostFinance Checkout Flex extension from PIT Solutions is a connector between PostFinance Checkout Flex and Odoo Web Shop. It is a standardized way to accept payments via a multitude of different payment providers in the world. It also supports payment gateways such as Postfinance pay, TWINT, Paypal, Online Banking, Credit/Debit Card. More information can be found under PostFinance Checkout Flex

The extension connects Odoo shop users to the payment hub, which has more than 50 payment gateways and processors linked to it. The Connector works with the help of the Rest API. This reduces the tendency of customers abandoning their cart when their preferred payment gateway is missing on the payment page. It also connects the user to the different payment service provider APIs, thereby lowering the payment routing costs.

PostFinance Checkout Flex extension from PIT Solutions is a connector between PostFinance Checkout Flex and Odoo Web Shop. It is a standardized way to accept payments via a multitude of different payment providers in the world. It also supports payment gateways such as Postfinance pay, TWINT, Paypal, Online Banking, Credit/Debit Card. More information can be found under PostFinance Checkout Flex.

PostFinance Checkout Flex back-end provides a configuration wherein one can define the Payment methods to be enabled for users. In addition to this, the admin has the flexibility to specify for the payment completion process the user should be redirected to the service's provider's site or handled within the shop site as I-frame. It depends on the payment service provider whether the gateway can be handled via redirection or I-frame or both.

Admin can enable the 3D secure functionality in the PostFinance Checkout Flex back-end for an additional security level in the payment process. If enabled, then during the checkout process user would be directed to the 3D secure service of the payment method and the details would be handled there.

One-Click Payments (Tokens Stored by PostFinance)

Customers can save their card with PostFinance and reuse it on future checkouts. The saved payment method is presented on the PostFinance hosted payment page (iFrame or Redirect). Odoo does not store tokens or card data.

How it works
  • Token creation and storage happen entirely in PostFinance.
  • During checkout (iFrame/Redirect), buyers can select their previously saved card.
  • No token objects are created in Odoo; reuse happens on the PostFinance page.

Enable One-Click in PostFinance (Back Office)

  1. Go to Settings -> Payment -> Payment Options -> Payment Methods.
  2. Open your card payment method (e.g., Visa/Mastercard).
  3. In One-Click Payment, set One-Click Payment Mode to:
    • Allow Storage - buyer can choose to save the card.
    • Force Storage - card is always saved when supported.
  4. Save in PostFinance.

Sync Methods in Odoo

  1. Open Accounting -> Configuration -> Payment Providers and select PostFinance.
  2. Click the Update Payment Methods smart button to pull the latest methods/settings from PostFinance.
  3. Publish/Activate the provider. No token-storage setting is required in Odoo.
Note: Managing saved cards (create/delete/permissions) is done in the PostFinance back office. Since Odoo doesn't hold tokens, they won't appear under customers in Odoo.

Limitations

Cryptocurrency Payment Unavailable: Please be aware that cryptocurrency payments powered by PostFinance are currently not supported. This limitation is due to PostFinance and is outside of our control. We recommend using alternative supported payment methods to complete your transaction.
